# Assessment Insights Visual Redesign

Updated the Phase 2 Assessment Insights interface to better match the existing premium RS8 Recruitment UI.

Changes:
- Replaced the oversized dark hero with a cleaner premium white panel.
- Added a red RS8-style feature icon to the Assessment Insights header.
- Increased typography sizes across the page, candidate cards, score breakdowns, and empty states.
- Added icons to the position, total applicants, strong fits, and top/average score cards.
- Improved candidate card spacing, score rings, detail panels, and insight button sizing.
- Redesigned Assessment Criteria Setup modal to match the Interview modal style.
- Added a dedicated modal header icon and a weight-summary icon.
- Increased modal labels, inputs, hints, mapped-question text, buttons, and question-list height.
- Preserved Phase 2 assessment logic, criteria mapping, weighting, and ranking behavior.
