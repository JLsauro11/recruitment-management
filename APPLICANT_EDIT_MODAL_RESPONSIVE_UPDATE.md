# Applicant Edit Modal Responsive Update

Updated the Applicants > Edit Applicant Information interface.

- Increased the desktop modal width to a fluid maximum of 1420px.
- Tablet modal now uses the available screen width with safe outer spacing.
- Mobile view switches to a full-screen editor.
- Form fields stack to one column on phones, use a clean two-column layout on tablets, and restore configured field widths on large desktops.
- Header and Save/Cancel footer stay accessible on mobile while scrolling long forms.
- Prevented horizontal form overflow, including file fields and long uploaded file names.
- Other compact system modals keep their existing size.
