# Assessment Insights - Head-to-Head Comparison V3

## What changed

The Candidate Comparison view is now evidence-first instead of score-only.

- Vacancy Qualification Match expands into a qualification-by-qualification matrix.
- Every vacancy requirement shows each candidate's exact status: Matched, Not met, or Needs verification.
- The exact evidence used for each qualification is displayed beside the status.
- Supporting categories now show structured evidence facts instead of only generic counts.
- Relevant Experience shows role-relevant duration, total verified duration, related job records, vacancy minimum, and positions used.
- Role-Specific Skills shows matched role terms, named tools/systems, evidence sources, and concrete action/result signals.
- Problem Solving shows action signals, result signals, role-context matches, and a short excerpt of the applicant's example.
- Role Evidence Quality shows answered evidence areas, role-context matches, action/result signals, and training-gap disclosure.
- Education & Certifications shows the exact degree/course, certifications/training, and professional qualifications submitted.
- Availability & Readiness shows exact start availability, notice period, and current employment status.
- Comparison badges now say Higher +N / Lower -N / Same score instead of only Stronger/Weaker.
- Key Differences now explains specific qualification conflicts and evidence differences rather than only reporting score gaps.

## Automatic upgrade

Assessment model version is now V3. Opening Assessment Insights automatically recalculates older V2 results once so the new structured comparison evidence is available without HR/Admin configuration.
