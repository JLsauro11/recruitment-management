# RS8 Premium Careers V2 Update

Updated the public careers landing page with a lighter, more premium recruitment design.

## UI updates
- New custom flat-vector illustrations inspired by modern recruitment landing page visuals.
- Larger typography and improved readability across hero, job listings, filters, culture, process, and CTA sections.
- Premium light RS8 palette using red accents with navy, blue, cream, and soft neutral backgrounds.
- Refined hero composition with recruitment illustration and floating status details.
- Redesigned job vacancy list with larger posters, stronger hierarchy, improved hover state, and responsive behavior.
- Improved search/filter panel and vacancy metadata presentation.
- Redesigned Life at RS8 and Application Process sections with custom vector illustrations.
- Responsive layouts retained for desktop, tablet, and mobile.

## Functional behavior retained
- Public careers landing page remains the main applicant entry point.
- Applicant must select a vacancy before continuing to the application form.
- Existing secure vacancy-selection flow remains unchanged.
- Existing job-poster upload and vacancy filtering remain unchanged.
- No new database migration is required for this visual update.
