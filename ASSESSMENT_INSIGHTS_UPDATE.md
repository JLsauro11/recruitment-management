# Assessment Insights - Phase 1

Added a new premium Assessment Insights module for Admin and HR.

## Included
- Vacancy-specific applicant ranking
- Overall role-fit score and fit labels
- Role Skills, Experience, Questionnaire, Education, and Profile Quality breakdown
- Assessment confidence indicator
- Strengths and interview validation gaps
- Role keyword evidence extracted from vacancy qualifications/description
- Expandable premium candidate insight cards
- Admin and HR sidebar navigation
- Fairness guardrail: demographic fields such as age, gender, religion, and address are not directly scored

## Scoring weights (Phase 1)
- Role Skills: 30%
- Experience: 25%
- Questionnaire: 25%
- Education: 10%
- Profile Quality: 10%

This first phase calculates insights dynamically from existing application/form data, so no database migration is required.

## Recommended Phase 2
Add editable assessment criteria/weights per vacancy, question-to-criterion mapping, saved assessment snapshots, candidate comparison mode, and AI-assisted qualitative scoring with auditable rubrics.
